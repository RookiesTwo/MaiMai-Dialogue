# 玩家交互

## 推进正文

- 按空格，或点击不属于按钮/滚动区域的对话画面进行推进。
- 当前正文或阻塞 Action 尚未完成时，第一次推进只会跳过剩余播放并提交最终状态。
- 当前 Step 已完成后，再次推进才会进入下一个 Step。
- 到达选项阶段后，点击空白区域不会推进，玩家必须选择一个可见选项。

对话界面不会暂停游戏世界，也不会提供自动播放。

## 选项与滚动

可见选项来自服务端访问查询。目标 `requires` 不满足的选项会被隐藏；内部错误或进度不可用会显示错误状态。

选项超过 Theme 的折叠数量限制时会出现展开按钮。折叠与展开状态都可滚动。

## 历史记录

右侧 History 入口显示本次 Dialogue UI session 已播放的正文和已确认的选项。进入子 Dialogue 或 Return 到 root 时历史仍保留。

历史只存在客户端内存中；关闭对话、死亡、断线或界面被替换后会立即清空，不写入存档，也不会同步到服务端。

## 关闭与 Return

- 根 Dialogue 执行 `return`：关闭界面。
- 子 Dialogue 执行 `return`：重新进入 root Dialogue 的开头，不恢复原来的 Step。
- Esc、关闭按钮、死亡、断线或其他 Screen 替换当前界面：结束本次 UI session。
- 对话已经打开时，新的服务端 `open` 请求不会替换当前对话。
